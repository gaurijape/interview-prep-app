- ✅ Sliding Window
- ⬜ Two Pointers
- ⬜ Prefix Sum
- ⬜ Kadane's Algorithm (max subarray)
- ⬜ Merge Intervals
- ⬜ Cyclic Sort

## Linked Lists
- ⬜ Fast & Slow Pointers (cycle detection)
- ⬜ In-place Reversal of a Linked List

## Trees & Graphs
- ⬜ BFS (level order / shortest path unweighted)
- ⬜ DFS (preorder/inorder/postorder, path finding)
- ⬜ Topological Sort
- ⬜ Union-Find (Disjoint Set)
- ⬜ Trie

## Heaps / Priority Queue
- ⬜ Top K Elements
- ⬜ Two Heaps (median tracking)
- ⬜ K-way Merge

## Backtracking
- ⬜ Subsets
- ⬜ Permutations
- ⬜ Combination Sum
- ⬜ N-Queens style constraint backtracking

- ⬜ Unbounded Knapsack
- ⬜ Longest Common Subsequence family
- ⬜ DP on Grids
- ⬜ DP on Trees

- ⬜ Classic Binary Search
- ⬜ Binary Search on Answer

## Greedy

- ⬜ Jump Game family

## Graph Algorithms
- ⬜ Dijkstra's Algorithm

- ⬜ Monotonic Queue

- ⬜ Sharding / Partitioning strategies
- ⬜ Replication (leader-follower, multi-leader, quorum)
- ⬜ Service Discovery
- ⬜ WebSockets / long-polling for real-time
